# Social Memory

> 상태: 제품 설계 단계 · 2026-09-13

Social Memory는 사용자가 X, Threads 등에서 저장하거나 반응한 자료를 로컬에 자동 보존하고, 이미 구독 중인 Claude Code·Codex·ChatGPT 같은 LLM에서 검색하고 활용하게 하는 오픈소스 로컬 지식 브리지다.

현재 결정:

- 데스크톱 앱 대신 로컬 서비스 + CLI + Agent Skill을 우선한다.
- SQLite와 로컬 파일 저장소가 원천 자료를 소유한다.
- X와 Threads는 코어가 아니라 선택형 커넥터다.
- `like`, `save`, `repost`는 서로 다른 Capture로 보존하고 계정별 수집 항목을 명시적으로 선택한다.
- 수집·추출·색인은 자동화하되 고급 분석은 사용자의 구독형 LLM을 활용한다.
- 로컬 MCP는 보조 인터페이스이며, Skill/CLI를 기본 운용 경로로 검토한다.
- 공개 저장소 생성과 구현은 제품 설계 승인 이후 진행한다.

내부 제품 문서:

- 별도 로컬 내부문서 라이브러리에 제품 설계 원본을 보관한다.
